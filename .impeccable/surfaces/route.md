# Surface Brief: /

## Scope and Mode

Public landing page for Annalist. Mode: **Persuade**. The visitor has not yet deployed the service and may not know the product. The page must make the offer intelligible, prove the mechanism, and drive deployment.

## Visitor

A developer or operator who ships releases on GitHub or Forgejo and is tired of hand-writing release notes. They are skeptical of marketing claims and respond to working proof and copy-paste adoption.

## Job and Action

Understand that Annalist writes release notes automatically from commit history, then act by copying the Docker command or reading the examples pack.

## Proof and Content

- A synthetic, clearly labeled generated release note in the hero, built from realistic commits.
- The three-step pipeline as measured "blows": Receive, Resolve, Strike.
- Docker pull command and a link to the examples pack as the primary actions.

## Direction

**"Forged Release Notes"** — the blacksmith's forge as a metaphor for the pipeline. Raw commits are heated, each summary is a measured blow, and a human-sounding release note exits as shaped metal. The visual system is forge-black ground, anvil-steel panels, a workpiece heat ramp from cherry to white-hot, one stenciled display face, and hairline rules that read like chalk marks on the shop floor.

## Memorable Moment

The visitor sees a glowing iron bar receive commit subjects one at a time, brighten with each "strike," and then reveal the generated release note as the shaped output.

## Constraints

- Must remain public; authenticated visitors are redirected to `/repos`.
- Must coexist with the existing graphite dashboard (The Copy Desk). The dashboard routes keep their current world; this page introduces a distinct Persuade surface.
- No fabricated customers, testimonials, or commercial claims.
